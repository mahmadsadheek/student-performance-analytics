Student Performance Analytics System

1. Project Overview

The Student Performance Analytics System is a Python-based data analysis project that analyzes student marks and attendance. It generates useful information about student performance, grades, examination results, and subject-wise averages.

2. Objective

The objective of this project is to use Python, NumPy, and Pandas to process student data and understand academic performance through numerical calculations and data analysis.

3. Technologies Used

- Python
- NumPy
- Pandas
- CSV (Comma-Separated Values)

4. Dataset Description

The project uses a CSV dataset containing 20 student records.

The dataset includes:

- Student ID
- Student Name
- Department
- Python Marks
- Java Marks
- DBMS Marks
- Computer Networks (CN) Marks
- Operating Systems (OS) Marks
- Attendance Percentage

5. Project Features

- Reads student data from a CSV file using Pandas.
- Calculates total marks and average marks.
- Assigns grades based on average marks.
- Identifies pass and fail students.
- Finds the highest and lowest performers.
- Calculates the overall class average.
- Performs subject-wise performance analysis.
- Displays pass/fail statistics.
- Generates a student performance report.

6. Implementation

The project uses Pandas to load and organize student records into a DataFrame. NumPy is used for numerical calculations, including totals, averages, highest marks, and lowest marks.

Python functions are used to calculate grades and determine pass/fail results. Loops and conditional statements are used to process records and analyze performance.

7. How to Run the Project

1. Install Python.

2. Install the required libraries:
   
   "python -m pip install pandas numpy"

3. Keep "main.py" and "students.csv" in the same folder.

4. Open the project folder in VS Code.

5. Run the program:
   
   "python main.py"

8. Expected Output

The program displays student totals, averages, grades, pass/fail results, the highest and lowest performers, subject-wise analysis, class statistics, and a final student performance report.

9. Learning Outcomes

This project helps demonstrate practical use of Python fundamentals, functions, loops, conditional statements, NumPy arrays, Pandas DataFrames, CSV files, and basic data analysis.
